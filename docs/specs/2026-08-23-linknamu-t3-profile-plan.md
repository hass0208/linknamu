# T3: 프로필 페이지 `/` 레이아웃 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `wireframe.png` 기준으로 원형 프로필 사진, 이름, 한 줄 소개를 `/`에 렌더링한다. create-next-app이 만든 기본 랜딩 마크업을 교체한다.

**Architecture:** `src/components/ProfileHeader.tsx` 컴포넌트를 새로 만들어 `src/config/links.ts`의 `profile`을 받아 렌더링하고, `src/app/page.tsx`에서 이를 사용한다. 이미지는 `next/image`로 원형 처리한다. 링크 카드 목록(T4)은 아직 없으므로 이 티켓에서는 `ProfileHeader`만 배치한다.

**Tech Stack:** Next.js 16 App Router, TypeScript, Tailwind CSS, `next/image`.

## Global Constraints

- 소스 디렉터리는 `src/` (`src/components/` 신설).
- TypeScript strict 모드 유지.
- 모바일 우선 반응형 (375px 폭 기준 우선 확인).
- 자동화 테스트 러너는 도입하지 않는다 — 브라우저 육안 확인 + `npm run build`로 검증한다 (프로젝트 스펙상 MVP 범위 제외).
- `profile.avatarPath`는 `/avatar.svg` (T2에서 이미 `public/avatar.svg`로 생성됨).

### Task 1: `ProfileHeader` 컴포넌트 작성

**Files:**
- Create: `src/components/ProfileHeader.tsx`

**Interfaces:**
- Consumes: `src/config/links.ts`의 `Profile` 타입, `profile` 상수 (`{ name, bio, avatarPath }`)
- Produces: `export default function ProfileHeader({ profile }: { profile: Profile })` — Task 2에서 `src/app/page.tsx`가 사용

- [ ] **Step 1: `ProfileHeader.tsx` 작성**

```tsx
import Image from "next/image";
import type { Profile } from "@/config/links";

export default function ProfileHeader({ profile }: { profile: Profile }) {
  return (
    <header className="flex flex-col items-center gap-3 px-6 pt-12 text-center">
      <Image
        src={profile.avatarPath}
        alt={`${profile.name} 프로필 사진`}
        width={128}
        height={128}
        priority
        className="h-32 w-32 rounded-full object-cover"
      />
      <h1 className="text-xl font-bold text-zinc-900">{profile.name}</h1>
      <p className="max-w-xs text-sm text-zinc-600">{profile.bio}</p>
    </header>
  );
}
```

- [ ] **Step 2: `src/app/layout.tsx`의 `metadata` 교체**
